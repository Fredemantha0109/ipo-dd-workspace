# IPO DD ワークスペース — 資料管理ガイド

## フォルダ構成

```
ipo_dd_workspace/
├── ipo_dd_workspace.html     ← ワークスペース本体
├── README.md                 ← このファイル
└── docs/
    ├── manifest.json         ← ファイル一覧（要更新）
    ├── SBI証券提出資料/
    ├── 取締役会・総会議事録/
    ├── 組織・規程/
    ├── 財務資料/
    └── その他/
```

## 資料を追加する手順

1. 該当フォルダにファイルをコピーする
   例）議事録 → docs/取締役会・総会議事録/20260427_取締役会議事録.pdf

2. docs/manifest.json をテキストエディタで開き、ファイル名を追記する

```json
{
  "docs/SBI証券提出資料/": ["SBI証券提出資料_2024Q1.pdf"],
  "docs/財務資料/": ["財務諸表_2024期.xlsx"],
  "docs/取締役会・総会議事録/": ["20260427_取締役会議事録.pdf"],
  "docs/組織・規程/": ["組織図_2026年版.pdf"],
  "docs/その他/": []
}
```

3. ブラウザでHTMLを開き直すと自動的にリンクが表示される

## 注意事項

- HTMLファイルとdocsフォルダは常に同じ場所に置いてください
- manifest.jsonはUTF-8で保存してください
- ファイルを削除したらmanifest.jsonからも削除してください
